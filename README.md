# ASYS Machinery

Учёт строительной техники: ежедневный журнал (машина → бригада → оператор), табель, поломки, отчёты.
Веб-приложение (PWA) на GitHub Pages; данные — Supabase (PostgreSQL), доступ только по e-mail и паролю.

- Приложение: https://asys-machinery.github.io/app/
- База: `db/schema.sql` (таблицы, роли, функции `mach_*`), тесты `db/test_schema.sql`
- Настройка подключения: скопируйте `config.example.js` → `config.js` и впишите URL и anon-ключ проекта Supabase.

## Объекты (несколько площадок) — с 10.11.2026
- Парк машин один на компанию; каждая машина находится на одном объекте или в **парке техники** (без объекта).
- Бригады, операторы, журнал дня, табель, поломки и запросы ведутся по объекту; участки и срок закрытия журнала — свои у каждого объекта.
- Перемещение машины: администратор — сразу (Справочники → «Переместить»), пользователь — через запрос; каждое перемещение пишется в журнал `machine_moves`.
- Доступ пользователя к объектам задаётся в Настройки → Пользователи (`people.sites`); администратор видит всё и режим «Все объекты».
- Переход существующей базы: `db/migrate_004_sites.sql` (SQL Editor). Все текущие данные привязываются к объекту `wb-astana`.
- `db/schema.sql` и `db/migrate_004_sites.sql` собираются из `db/parts/*.sql` скриптом `python3 db/build_sql.py`.

## Тесты
- База: `bash db/run_tests.sh` (локальный PostgreSQL) — функции и права; миграция проверяется и на схеме v1.
- Интерфейс: `node tests/app.test.js` (сквозные сценарии), `node tests/smoke.test.js` («нажать каждую кнопку», 3 роли × 2 языка), `node tests/legacy.test.js` (новый интерфейс на базе до миграции).
